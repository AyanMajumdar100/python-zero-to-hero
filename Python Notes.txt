PYTHON DEFAULT SORTING : 
========================
**Timsort** is a fast hybrid sorting algorithm combining Merge Sort and Insertion Sort, utilizing natural runs and balanced merging. It was created by Tim Peters in 2002 for Python and serves as the default sorting method in Python, Java, and Swift.

How Timsort Works
Finds runs: It scans the data for small chunks that are already sorted (natural runs).
Insertion sort: If a run is too small (less than 32–64 elements), it uses insertion sort to size it up.
Merges runs: It merges the sorted chunks together using a smart stack rule to keep merges balanced.
Key Features
Adaptive: Runs in O(n) time on pre-sorted data.
Stable: Keeps equal elements in their original order.
Efficient: Operates at (O(nlog n)) time in average and worst cases.
